
# Enterprise Multi-LAN Network

## Project Overview
This project designs and simulates an enterprise network
using Cisco Packet Tracer.

## Objectives
- Design a network with three sites.
- Configure VLANs and trunk links.
- Configure inter-VLAN routing.
- Configure DHCP.
- Implement OSPF dynamic routing.
- Apply ACLs for traffic control.
- Test connectivity and troubleshoot issues.

## Technologies
- Cisco Packet Tracer
- VLAN and Trunking
- Inter-VLAN Routing
- DHCP
- OSPF
- ACL
- IPv4 Subnetting

## Project Files
- `enterprise-multi-lan.pkt` - Packet Tracer topology
- `docs/` - Network design and IP addressing
- `configs/` - Device configurations
- `screenshots/` - Testing evidence
